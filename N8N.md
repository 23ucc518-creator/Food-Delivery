# 🤖 NL-to-SQL Workflow (n8n)

As an extension to the SQL analysis, a **natural language to SQL** workflow was built in n8n — allowing business questions to be asked in plain English and answered directly from the MySQL database, without writing SQL manually.

## ⚙️ How It Works

The workflow consists of 4 connected nodes:

| Node | Role |
|---|---|
| **When chat message received** | Trigger — captures the user's natural language question |
| **AI Agent** | Core orchestrator — interprets the question and decides what SQL to run |
| **Google Gemini Chat Model** | LLM powering the AI Agent's reasoning and query generation |
| **Execute a SQL query in MySQL** | Tool — runs the AI-generated SQL directly against the `fooddelivery` database and returns results to the agent |

**Flow:** User asks a question in chat → AI Agent (using Gemini) converts it into a SQL query based on the database schema → the SQL tool executes it against MySQL → Gemini formats the raw result into a clear, human-readable answer → response is returned in chat.
